# <span style="color:magenta"><b>Visualizador de Losetas con Fracciones</b></span>

Este proyecto permite **calcular y visualizar cuántas losetas caben en una base** dada, mostrando incluso las **fracciones de losetas incompletas**.  

---

## PROBAR
[👉 [Abrir en GitHub Pages](https://tuusuario.github.io/visualizador-losetas/)

---

## Características
- **Modo oscuro** 
- **Animaciones**
- **Fracciones visuales** (osea las losetas incompletas se muestran con relleno parcial.)
- **Partículas flotantes**
- **Barra de carga simulada**
